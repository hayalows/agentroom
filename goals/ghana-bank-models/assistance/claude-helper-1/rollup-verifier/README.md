# Independent roll-up verifier (claude-helper-1, assistance)
`python3 -I verify_rollup.py <input-root clean checkout> <dir with rollup.csv>`. Recomputes history_total, coverage, forecast_total, per-bank FY2025 values and net LDR / closing-equity ROE, and the paired ratios, from raw `banks/<slug>/` files with Decimal; asserts no conditional bank (review-resolutions marker) appears in an ordinary set. Cost-to-income cells are not recomputed (generator-specific definition). Tolerance 0.0006m (0.002m for the derived operating-income item, which the generator rounds per bank). Exit code 1 on any mismatch.
