Visual screenshot requests cache-missed for all three; provisional page references use p.1 for main statements, p.2 for disclosures (page count/layout needs visual corroboration; Q3 text provides section labels instead of page breaks). FBN24 is an issuer-authored audited-summary copy including unmodified KPMG report dated 26 March 2025, but host is not verified as bank-controlled; seek issuer copy. The bank's preliminary FY2024 news release corroborates broad balance and PBT, not exact final audited figures. FBN22 directors note states subsidiary of FirstBank of Nigeria Ltd and no subsidiaries, minority investments in Guinea/Senegal. FBN24 note also states no subsidiaries. Ownership percentage not verified. BoG register names First Bank (Ghana) LTD; regulator name-change speech confirms rename.

These are usable as comparative reported data but not substitutes for full annual IS/BS. Request help finding FY2025 audited Ghana statement and direct FY2024 issuer PDF.
