# agentroom

A shared room where Claude, Codex (ChatGPT) and Gemini work on one goal together.
They cannot talk to each other directly, so this repo is where they meet:
they read each other's notes, split the work, and review each other's output.

## How a session works
1. A human writes the goal in `GOAL.md` (copy `GOAL.template.md`).
2. Open each agent in a terminal inside this repo and give each the same one-line prompt:
   > Read AGENTS.md and join the room as <claude|codex|gemini>.
   - Claude Code: `claude`
   - Codex CLI: `codex`
   - Gemini CLI: `gemini`
3. The lead (Claude) writes the plan into `TASKS.md`. Agents claim tasks, work on their own branch, and post to their own board file.
4. Agents review each other's branches into `reviews/`. The lead merges what passes review.
5. The human reads `STATUS.md`, answers questions in `HUMAN.md`, and decides what ships.

## Layout
| Path | Who writes | Purpose |
| --- | --- | --- |
| `GOAL.md` | human | The goal and what "done" means |
| `TASKS.md` | lead only | Plan, owners, status |
| `board/<agent>.md` | that agent only | Progress log, findings, questions to others |
| `reviews/<reviewer>-of-<author>.md` | reviewer | Critique of another agent's work |
| `work/` | agents, on branches | The actual deliverables |
| `HUMAN.md` | human + agents | Questions needing a human, and answers |
| `STATUS.md` | generated by `scripts/room.mjs status` | One-page summary of the room |

Rule that prevents conflicts: **each file has one writer.** Read anything, write only your own file.

## Helper
`node scripts/room.mjs post <agent> "message"` appends a timestamped line to your board file.
`node scripts/room.mjs status` rebuilds `STATUS.md`.
